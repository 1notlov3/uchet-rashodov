# Устройство программы

## Файлы
- rashody.py – программа;
- rashody.csv – файл с расходами (создаётся сам при первом расходе);
- test_rashody.py – проверки программы.

## Формат файла rashody.csv
Одна строка – один расход, поля разделены точкой с запятой:

    дата;категория;сумма;комментарий
    18.11.2026;Еда;250.0;обед в столовой

## Функции программы
| Функция | Что делает |
|---|---|
| load_expenses | читает расходы из файла |
| save_expenses | записывает расходы в файл |
| add_expense | спрашивает данные нового расхода и сохраняет его |
| show_expenses | выводит все расходы |
| totals | считает суммы по категориям или по месяцам |
| show_totals | выводит посчитанные суммы и общий итог |
| main | показывает меню и вызывает нужную функцию |
