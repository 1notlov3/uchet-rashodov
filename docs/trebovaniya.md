# Требования к программе «Учёт личных расходов»

## Для кого программа
Для студента, который хочет знать, куда уходят его деньги.
Программа работает на одном компьютере, без интернета и регистрации.

## Что должна уметь программа
1. Добавлять расход: дата, категория, сумма в рублях, комментарий.
2. Если дата не введена, ставить сегодняшнюю.
3. Показывать список всех расходов.
4. Считать сумму расходов по каждой категории.
5. Считать сумму расходов по каждому месяцу.
6. Хранить расходы в файле rashody.csv, чтобы они не пропадали
   после закрытия программы.

## Категории
Еда, Транспорт, Учёба, Связь, Развлечения, Другое.

## Ошибки ввода
Если категория или сумма введены неправильно, программа пишет
об ошибке и ничего не сохраняет.
