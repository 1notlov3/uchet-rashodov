# Учёт личных расходов

Учебный проект по дисциплине «Проектная деятельность в ИТ»
(Московский университет имени С.Ю. Витте).

Автор: Грачев Максим, группа о.ИЗДтс 23.1/БЗ-25.

Простая программа для командной строки: записывает личные расходы
в файл и считает, сколько денег ушло на каждую категорию и за каждый месяц.
