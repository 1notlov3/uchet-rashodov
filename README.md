# Учёт личных расходов

Учебный проект по дисциплине «Проектная деятельность в ИТ»
(Московский университет имени С.Ю. Витте).

Автор: Грачев Максим, группа о.ИЗДтс 23.1/БЗ-25.

Простая программа для командной строки: записывает личные расходы
в файл и считает, сколько денег ушло на каждую категорию и за каждый месяц.

## Как запустить

Нужен Python 3.10 или новее, дополнительные библиотеки не нужны.

    python rashody.py

Расходы сохраняются в файл `rashody.csv` рядом с программой.

## Что умеет программа

1. Добавить расход: дата, категория, сумма и комментарий.
2. Показать все расходы.
3. Посчитать итоги по категориям.
4. Посчитать итоги по месяцам.
